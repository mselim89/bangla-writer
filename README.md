# Bangla AI Voice Writer - Android Studio Project

## অ্যাপটির পরিচিতি ও বৈশিষ্ট্য
এই প্রজেক্টটি একটি সম্পূর্ণ কার্যকর নেটিভ অ্যান্ড্রয়েড অ্যাপ্লিকেশন যা:
1. স্ক্রিনের যেকোনো প্রান্তে ড্র্যাগ করা যায় এমন একটি ফ্লোটিং 🎙️ বাটন প্রদর্শন করে (`WindowManager`).
2. ব্যবহারকারীর কণ্ঠস্বর ক্যাপচার করে Whisper AI / Groq STT দিয়ে দাঁড়ি (।), কমা (,) সহ সাবলীল বাংলায় রূপান্তর করে।
3. অ্যান্ড্রয়েডের `AccessibilityService` এর মাধ্যমে সরাসরি সক্রিয় থার্ড-পার্টি অ্যাপের (যেমন: WhatsApp, Messenger, Facebook, Notepad ইত্যাদি) টেক্সট ফিল্ডে স্বয়ংক্রিয়ভাবে লিখে দেয়।

## কিভাবে APK তৈরি এবং মোবাইলে ইন্সটল করবেন (How to Build & Install APK)

### পদ্ধতি ১: Android Studio দিয়ে ১-ক্লিকে APK তৈরি (সবচেয়ে সহজ)
1. জিপ (`.zip`) ফাইলটি আনজিপ করুন।
2. আপনার কম্পিউটারে **Android Studio** ওপেন করুন।
3. **Open Project**-এ ক্লিক করে `BanglaVoiceWriter` ফোল্ডারটি সিলেক্ট করুন।
4. গ্রেডল সিঙ্ক শেষ হলে ওপরের মেনু বার থেকে:
   `Build` > `Build Bundle(s) / APK(s)` > `Build APK(s)`-এ ক্লিক করুন।
5. কয়েক সেকেন্ডের মধ্যে নিচে `locate` লিংক আসবে, সেখানে ক্লিক করলেই আপনার কাঙ্ক্ষিত `app-debug.apk` ফাইলটি পেয়ে যাবেন!
6. ফাইলটি আপনার মোবাইলে পাঠিয়ে ইন্সটল করুন।

## প্রথমবার ব্যবহারের জন্য প্রয়োজনীয় সেটিংস
অ্যাপটি ওপেন করে দুটি পারমিশন এনেবল করতে হবে:
1. **Overlay Permission:** "অন্য অ্যাপের উপরে প্রদর্শন" অপশনটি চালু করুন।
2. **Accessibility Permission:** সেটিংসে গিয়ে "Installed apps / Accessibility" থেকে "Bangla Voice Writer" অপশনটি ON করুন।
3. আপনার Groq বা OpenAI API Key দিয়ে "সেভ করুন" বাটনে চাপুন।
4. এরপর "ভাসমান মাইক বাটন চালু করুন" চাপলেই স্ক্রিনে 🎙️ বাটন চলে আসবে! যেকোনো অ্যাপে গিয়ে বাটনে চাপ দিয়ে বাংলায় কথা বললেই সরাসরি লেখা শুরু হবে।
